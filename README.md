# FocusFeed AI (Prototype)

> **It's just a prototype.** This is a UI demo only. It has no backend, no login, and no real integration with any social app.

FocusFeed AI is a concept for an anti-addiction social app. It shows your messages and study updates, and hides infinite feeds like Reels, Shorts and Spotlight.

## Screens
- **Dashboard:** Daily AI Brief, sanitized social apps, and a shortcut to the inbox
- **Focus Inbox:** direct messages only, with Important / Learning / Social filters
- **Chat with "No-Escape Barrier":** reply without being pulled back into a feed, with a daily reel budget of 5
- **Settings:** feed-blocking toggles and notification sensitivity

## Run it
Open `index.html` in a browser. No install needed.

## Tech
HTML, Tailwind CSS (CDN), Phosphor Icons, vanilla JavaScript. The Tailwind CDN is fine for a demo but not meant for production.
